# Проверки проекта

Запусти по очереди и собери результаты; при падении одного шага всё равно выполни остальные:

1. `npm run type-check` — vue-tsc.
2. `npx oxlint .` и `npx eslint .` — **без `--fix`**: npm-скрипт `lint` правит файлы, а здесь нужен только отчёт.
3. `npx prettier --check src/`
4. Если передан `--build` (`$ARGUMENTS`) — `npm run build-only`.

## Отчёт

Таблица: проверка → ✅/❌ → число проблем.

Для каждой ошибки — файл и строка ссылкой, причина простыми словами и как исправить (подсказка, не правка). Однотипные ошибки группируй.

Файлы не правь: пользователь исправляет сам. Исключение — он прямо попросил, например «почини форматирование»; тогда допустимо `npm run format` / `npm run lint`.
