# Проверка UI: $ARGUMENTS

## 1. Подготовка

- Dev-сервер должен работать на http://localhost:5173. Если нет — попроси пользователя запустить `npm run dev`.
- Если MCP chrome-devtools недоступен — скажи об этом и предложи `/mcp` для переподключения.

## 2. Проверки через chrome-devtools

1. Открой `http://localhost:5173$ARGUMENTS` (если аргумента нет — `/`) и дождись загрузки.
2. **Консоль**: ошибки и warning'и Vue (например, «Missing required prop», «Extraneous non-props attributes»).
3. **Сеть**: запросы на `/api/football/*` — сколько их, статусы, нет ли дублей. Перезагрузи страницу или перейди на другой экран и обратно: кэш store не должен давать повторных запросов. Отметь 403/429.
4. **Скриншот** на десктопе (1280px) и на мобильном (375px): сломанная вёрстка, горизонтальный скролл, обрезанный текст.
5. **Доступность** через снапшот страницы: картинки без alt, кнопки без доступного имени, порядок заголовков.

## 3. Отчёт

- Скриншоты.
- Список проблем по важности; у каждой — вероятная причина в коде (файл, если удаётся определить) и подсказка, как исправить.
- Отдельная строка — число запросов к API на этой странице.

Код не правь: пользователь исправляет сам.
